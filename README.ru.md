# remnaWake

[English](README.md) · **Русский**

Лёгкий Go-сервис, который раз в сутки опрашивает панель
[Remnawave](https://remna.st) и уведомляет пользователей в Telegram об истечении
подписки (за 7 / 3 / 1 день). Дополнительно администратор может прямо из Telegram
подтвердить оплату — и бот продлит подписку на выбранное число месяцев.

## Возможности

- Один ежедневный запуск по cron (`go-co-op/gocron/v2`) в заданной таймзоне.
- Авторизация в Remnawave через API-токен панели (`Authorization: Bearer ...`).
- Получение пользователей `GET /api/users` с пагинацией по `start/size`.
- Обработка только `status == "ACTIVE"`, пользователи без `telegramId` пропускаются.
- Отправка сообщений через Telegram Bot API (`sendMessage`).
- Inline-кнопка **«Я оплатил»** в уведомлениях и подтверждаемый администратором
  сценарий продления подписки через `PATCH /api/users`.
- **`/register`** — самостоятельная привязка Telegram: пользователь вводит имя
  профиля в Remnawave, бот находит аккаунт и привязывает Telegram ID без участия
  администратора.
- **`/invite`** — действующие подписчики могут запросить создание нового
  пользователя в панели; администратор одобряет, и бот отправляет ссылку на
  подписку обратно пригласившему.
- Приветственное сообщение при команде `/start`.
- Структурированные логи в stdout (`log/slog` JSON).
- Multi-stage Docker-образ на базе `distroless/static`, `restart: unless-stopped`.

## Текст уведомления

```
⏰ Подписка истекает через 7 дней. Для продления оплатите подписку.
⏰ Подписка истекает через 3 дня. Для продления оплатите подписку.
⏰ Подписка истекает через 1 день. Для продления оплатите подписку.
```

Слово «день/дня/дней» согласуется с числом.

Если задан `TELEGRAM_ADMIN_ID`, к сообщению добавляется inline-кнопка
«Я оплатил». Используйте именно **Telegram ID администратора** (user ID), а не
chat ID группы/канала.

## Сценарий подтверждения оплаты (опционально)

Активен только при заданном `TELEGRAM_ADMIN_ID`:

1. Пользователь нажимает **«Я оплатил»** под уведомлением об истечении. Если
   администратор задал **реквизиты для оплаты** (см. `/setrequisites` ниже), бот
   сначала отправляет их пользователю (например, номер карты или данные СБП).
2. Если администратор задал тарифы, бот показывает на сообщении варианты
   месяцев и цен (например, `1 мес. — 150₽`, `3 мес. — 450₽`, плюс кнопка
   «← Назад»), и пользователь выбирает один. Если тарифы **не заданы**, работает
   запасной вариант — заявка на 1 месяц.
3. Бот отправляет **администратору** данные клиента и выбранные месяцы/цену с
   кнопкой **«Подтвердить оплату»**.
4. Администратор подтверждает. Бот вызывает `PATCH /api/users` (с `uuid` в теле
   запроса) и продлевает подписку на **выбранное число месяцев** (от
   `max(сейчас, текущий срок)`), затем сообщает новый срок действия.

Цены **информационные** — бот не проводит платежи. Пользователь платит вам
внешним способом, а вы подтверждаете вручную.

### Команды

**Команды пользователя** (доступны всем, кто пишет боту):

| Команда       | Что делает                                                              |
| ------------- | ----------------------------------------------------------------------- |
| `/start`      | Показать приветственное сообщение                                       |
| `/menu`       | Открыть меню с inline-кнопками                                          |
| `/tariff`     | Показать текущие тарифы/цены                                            |
| `/payff`      | Оплатить за другого пользователя (только для подписчиков)               |
| `/invite`     | Пригласить нового пользователя в панель (только для подписчиков)        |
| `/register`   | Привязать свой Telegram к существующему профилю Remnawave               |
| `/cancel`     | Отменить текущий шаг `/payff`, `/invite` или `/register`                |
| `/help`       | То же, что `/menu`                                                       |

**Команды администратора** (только аккаунт с ID, равным `TELEGRAM_ADMIN_ID`; для
остальных молча игнорируются):

| Команда                       | Что делает                  |
| ----------------------------- | --------------------------- |
| `/tariffs`                    | Список тарифов              |
| `/settariff <месяцев> <цена>` | Добавить или обновить тариф |
| `/deltariff <месяцев>`        | Удалить тариф               |
| `/setrequisites`              | Задать реквизиты для оплаты, которые показываются пользователю после «Я оплатил» (в два шага: команда, затем текст следующим сообщением) |
| `/requisites`                 | Показать текущие сохранённые реквизиты |

Тарифы и состояние оплат хранятся в SQLite (`DB_PATH`, по умолчанию
`/data/bot.db`, в Docker-томе `botdata`), поэтому переживают перезапуск.

### Кнопки меню

По команде `/menu` (или `/help`) бот присылает четыре inline-кнопки:

| Кнопка                        | Действие                                     |
| ----------------------------- | -------------------------------------------- |
| 💵 Тарифы                    | Показать текущие цены                        |
| 💳 Оплатить за другого        | Начать сценарий оплаты за другого            |
| 👤 Пригласить пользователя    | Начать сценарий приглашения нового           |
| 🔗 Привязать аккаунт          | Начать привязку Telegram к профилю           |

### Оплата за другого пользователя (`/payff`)

Любой действующий подписчик может оплатить подписку другому человеку:

1. Отправьте боту `/payff`.
2. Введите **имя пользователя Remnawave** или **Telegram ID** получателя (если
   значение состоит только из цифр — поиск по Telegram ID, иначе по имени).
3. Выберите период на кнопках тарифов (или единственный вариант на 1 месяц, если
   тарифы не заданы). Отмена — командой `/cancel` или кнопкой **«Отмена»**.
4. Администратор получит заявку с именами плательщика и получателя и кнопкой
   **«Подтвердить оплату»**. Подтверждение продлевает подписку получателя.

Команда `/payff` доступна только действующим подписчикам; каждая заявка
подтверждается администратором.

### Приглашение нового пользователя (`/invite`)

Любой действующий подписчик может запросить создание нового аккаунта в панели:

1. Отправьте боту `/invite`.
2. Введите желаемое **имя пользователя** для нового участника (3–32 символа,
   буквы / цифры / нижнее подчёркивание).
3. Бот покажет стоимость (цена тарифа на 1 месяц) и кнопку **«Отправить заявку»**.
   `/cancel` отменяет.
4. Администратор получит заявку с кнопками **«✅ Одобрить»** и **«❌ Отклонить»**.
   При одобрении бот создаёт пользователя в панели и отправляет ссылку на подписку
   пригласившему.

Команда `/invite` доступна только действующим подписчикам; каждая заявка
подтверждается администратором.

### Привязка Telegram к профилю (`/register`)

Пользователи, у которых уже есть аккаунт Remnawave, но Telegram не привязан,
могут сделать это самостоятельно — без обращения к администратору:

1. Отправьте боту `/register` (или нажмите **🔗 Привязать аккаунт** в меню).
2. Введите **имя профиля Remnawave** (видно в VPN-приложении).
3. Бот найдёт аккаунт. Если профиль существует и Telegram ещё не привязан, бот
   попросит подтверждение.
4. Нажмите **«Привязать»** — бот вызовет `PATCH /api/users` и сразу привяжет
   ваш Telegram ID к профилю.

Если профиль уже привязан к вашему Telegram — бот подтвердит это идемпотентно.
Если привязан к чужому — откажет и попросит обратиться к администратору.
Сессия истекает через 10 минут бездействия.

**Как найти:** при запуске бот регистрирует меню команд (через `setMyCommands`),
поэтому у пользователей появляется синяя кнопка **Меню** и автодополнение по `/`
для всех команд выше. По команде `/menu` (или `/help`) бот пришлёт четыре
inline-кнопки.

Защита:

- Подтверждать оплату, одобрять приглашения и управлять тарифами может только
  заданный администратор.
- Подтверждение оплаты **идемпотентно**: повторные нажатия не продлят подписку дважды.
- Новый срок = `max(сейчас, текущий срок)` + выбранные месяцы, поэтому позднее
  подтверждение не оставит дату в прошлом.

## Приветственное сообщение

При отправке команды `/start` бот отправляет приветственное сообщение:

```
⏰ Привет! Я бот-напоминалка: если ваша подписка на КВН скоро закончится, я сообщу об этом заранее — за 7, 3 или 1 день до окончания.

Меню и команды:
/menu — открыть меню с кнопками
/tariff — посмотреть текущие тарифы
/payff — оплатить подписку за другого пользователя
/cancel — отменить текущее действие

После оплаты нажмите «Я оплатил» — администратор получит уведомление и подтвердит продление.
```

## Конфигурация (.env)

| Переменная               | Обязательна | По умолчанию      | Описание                                                         |
| ------------------------ | ----------- | ----------------- | ---------------------------------------------------------------- |
| `REMNAWAVE_BASE_URL`     | да          | —                 | Базовый URL панели                                               |
| `REMNAWAVE_API_TOKEN`    | да          | —                 | API-токен панели Remnawave                                       |
| `TELEGRAM_BOT_TOKEN`     | да          | —                 | Токен Telegram-бота (от @BotFather)                              |
| `TELEGRAM_PARSE_MODE`    | нет         | `HTML`            | `HTML` / `MarkdownV2` / пусто                                    |
| `TELEGRAM_ADMIN_ID`      | нет         | `0`               | Telegram user ID администратора для оплаты/приглашений/привязки (`0` — выкл.) |
| `TZ`                     | нет         | `Europe/Moscow`   | IANA-таймзона                                                    |
| `RUN_AT`                 | нет         | `09:00`           | Локальное время ежедневного запуска (`HH:MM`)                    |
| `LOG_LEVEL`              | нет         | `info`            | `debug` / `info` / `warn` / `error`                              |
| `HTTP_TIMEOUT`           | нет         | `15s`             | Таймаут HTTP-запросов (Go duration)                              |
| `DRY_RUN`                | нет         | `false`           | Писать в лог, не отправлять в Telegram                           |
| `RUN_ON_START`           | нет         | `true`            | Выполнить задачу сразу при старте                                |
| `DB_PATH`                | нет         | `/data/bot.db`    | Путь к файлу базы данных SQLite                                  |
| `CURRENCY`               | нет         | `₽`               | Обозначение валюты рядом с ценами тарифов                        |

## Запуск

### Установка на сервер (рекомендуется)

Одна команда скачивает проект в **`/opt/remnaWake`** и запускает интерактивный
установщик. Для установки в `/opt` нужны права root, поэтому запускайте от root
или через `sudo`:

```bash
curl -fsSL https://raw.githubusercontent.com/Nakedjustice/remnaWake/main/get.sh | sudo bash
```

Чтобы установить в другое место (для доступного на запись пути root не нужен),
задайте `TARGET_DIR`:

```bash
curl -fsSL https://raw.githubusercontent.com/Nakedjustice/remnaWake/main/get.sh | TARGET_DIR="$HOME/remnaWake" bash
```

Предпочитаете вручную?

```bash
sudo git clone https://github.com/Nakedjustice/remnaWake.git /opt/remnaWake
cd /opt/remnaWake
sudo ./install.sh
```

Установщик спросит URL панели, API-токен, токен бота, Telegram ID администратора,
таймзону и время запуска, запишет `.env` (с правами `600`) и предложит скачать
готовый образ и запустить контейнер через Docker Compose. Нужны `git` (либо
`curl`/`wget`) и Docker Engine с плагином Compose.

### Локально (разработка)

```bash
cp .env.example .env
# отредактируйте .env
go mod download
go run .
```

### Docker (готовый образ)

Готовый к запуску образ публикуется в GHCR, локальная сборка не нужна:

```bash
cp .env.example .env
# отредактируйте .env и укажите TELEGRAM_ADMIN_ID для всех дополнительных сценариев
docker compose up -d          # скачивает ghcr.io/nakedjustice/remnawake:latest
docker compose logs -f
```

Чтобы обновиться позже, скачайте свежий образ и пересоздайте контейнер:

```bash
docker compose pull && docker compose up -d
```

### Docker (сборка из исходников)

Если вы изменили код (или используете свой форк) и хотите собрать образ локально
вместо скачивания, используйте override-файл для сборки:

```bash
docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

## Поведение

- Если ответ Remnawave содержит `total > size`, сервис догружает остальные страницы.
- На `401` от `/api/users` проверьте `REMNAWAVE_API_TOKEN`. Ошибка логируется, job не падает.
- Telegram `429` логируется с указанием `retry_after`, остальные пользователи
  продолжают обрабатываться.
- При заданном `TELEGRAM_ADMIN_ID` бот запускает long polling для
  `callback_query` и `message`, чтобы обрабатывать все inline-кнопки и команды.
- Дедупликация уведомлений — точное совпадение оставшихся дней (`7/3/1`) на дату
  запуска. Состояние уведомлений не сохраняется.

## Развёртывание своей копии

Чтобы разместить бота в своём репозитории GitHub (чтобы установщик в одну строку
работал для вас и ваших пользователей), запушьте проект в **публичный** репозиторий:

```bash
# из каталога проекта
git remote add origin https://github.com/<вы>/<репозиторий>.git
git push -u origin main
```

Затем замените `Nakedjustice/remnaWake` (и ветку `main`) на свой
`<вы>/<репозиторий>` в файлах `get.sh`, `README.md` и `README.ru.md`, а также путь
`module` в `go.mod`. Файл `.env` добавлен в `.gitignore` и никогда не пушится —
ваши API-токены остаются приватными.

Workflow `.github/workflows/docker-publish.yml` публикует готовый образ в **ваш**
GHCR (`ghcr.io/<вы>/<репозиторий>`, в нижнем регистре) при каждом пуше в `main`.
Обновите строку `image:` в `docker-compose.yml` под свой `ghcr.io/<вы>/<репозиторий>`
(в нижнем регистре). Пакет создаётся после первого успешного запуска — сделайте
его публичным в настройках **Packages** репозитория, чтобы пользователи могли
скачивать образ без авторизации. До этого (и в любой момент) можно собирать из
исходников через override `docker-compose.build.yml`, показанный выше.

После пуша проверьте, что установщик доступен:

```bash
curl -fsSL https://raw.githubusercontent.com/<вы>/<репозиторий>/main/get.sh | head -5
```
